# Tender Analyzer - Frontend

React frontend for visualizing Portuguese government tender analysis results.

## Setup

```bash
npm install
npm start
```

The app will open at http://localhost:3000.

> **Note:** The backend must be running at http://localhost:5000 for API calls to work.

## Features

- **Dashboard** – Overview statistics and tender list
- **Search** – Filter tenders by keyword
- **URL Analyzer** – Paste a tender URL to analyze it directly
- **Relevance Filter** – Filter by High / Medium / Low Microsoft relevance
- **Tender Detail** – Full analysis with matched keywords and opportunity tags

## Build for Production

```bash
npm run build
```
